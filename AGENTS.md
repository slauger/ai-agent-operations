# Hinweise für Coding-Agenten

Dieses Repository beschreibt ein Referenzkonzept für den Betrieb von KI-Agenten (Text und Diagramme). Es gibt hier keinen Code.

## Regeln

- Sprache Deutsch, sachlich und direkt, für technisch erfahrene Leser (Betrieb, Plattform, Sicherheit). Fachbegriffe beim ersten Auftreten kurz erklären.
- Kein Markdown line wrapping: jeder Absatz ist eine einzelne Zeile.
- Nur ASCII-Interpunktion: keine Gedankenstriche (Em-Dash, En-Dash), keine typografischen Anführungszeichen, kein Ellipsis-Zeichen. Echte Umlaute und ß verwenden (nicht ae, oe, ue, ss).
- Diagramme als Mermaid im Markdown, damit sie im Repository und auf der Website gleich aussehen.
- Produkte dürfen genannt werden, Hosts, Konten, Tokens und Personen nicht. Beispiel-Hosts nutzen `example.org`.
- Jede Aussage über den Stand trägt eine Kennzeichnung: umgesetzt (im Proof of Concept gelaufen), geplant oder offen.
- Lücken in der Spezifikation (AWP) bekommen hier keine eigenen Nummern; sie verweisen auf die Liste der Laufzeit-Rückmeldungen im AWP-Repository (G-Nummern).
- Conventional Commits verwenden.
